# 0.1.0 (2026-10-14): first experimental nodes

Five nodes, all labelled **experimental**: tested on CPU, not yet benchmarked on real LTX weights.

- **LTXE Resolution Plan**, **LTXE Pad Frames**, **LTXE Crop Back**: aligned canvas (DCP 2K 1920x1088, DCP 4K
  4096x2176, UHD, source size, custom), pad modes reflect / replicate / constant, fit pad / fit-inside /
  crop-to-fill, 8k+1 frames; exact crop-back, also after a uniform upscale; optional VAE input reads the VAE's
  own scale factors.
- **LTXE Tiled Model**: tiles each model call inside core's APPLY_MODEL wrapper chain and blends the x0
  predictions with trapezoid weights (endpoints excluded); any sampler; LTX-2 audio-video latents share the audio
  across tiles. Refuses IC-LoRA guide / keyframe tokens and ControlNet with a plain message (next slice).
- **LTXE Sigma Check**: catches the NaN, flat, staircase and saturated schedules core's LTX schedulers give on
  large latents (crash_repros/001).
- Planning core `ltx_enhanced/` (no ComfyUI import), design document `docs/design/architecture.md`.
- CI workflow and UI smoke test (shared C2C templates).

Evidence: 93 tests (`python -m pytest tests`), including runs inside core's sampler with tiny random LTXV and
LTXAV models; live check on core 0.39.0 + frontend 1.53.10, both renderers, root and inside a subgraph.
