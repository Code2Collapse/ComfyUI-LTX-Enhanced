# 0.3.0 (2026-10-14): out-of-memory recovery, long clips with core context windows

- **LTXE Tiled Model** has `on_out_of_memory`:
  - *shrink tiles* (the default): free memory, halve the larger tile side, retry (down to 128 px, at most 6 times),
    and keep the smaller size for the rest of the run. A tile as large as the frame means "tile only if needed".
  - *stop*: fail at once.
  - At the smallest size it stops with a plain message.
- **Long clips:** verified that ComfyUI core's LTXV Context Windows (temporal) and LTXE Tiled Model (spatial)
  compose, in either wrapping order. One tile leaves a context-window run bit-identical.
- Still **experimental**. The memory recovery is tested on CPU with a model that fails above a budget; real-GPU
  behaviour is not measured yet.

Evidence: 115 tests (`python -m pytest tests`).
