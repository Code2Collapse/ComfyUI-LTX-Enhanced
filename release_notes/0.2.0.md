# 0.2.0 (2026-10-14): IC-LoRA guides in LTXE Tiled Model

- **LTXE Tiled Model** now tiles calls that carry IC-LoRA / LTXV Add Guide tokens:
  - the appended guide frames are cut with each tile;
  - their per-token pixel coordinates (`keyframe_idxs`) are cropped to the tile's cells and shifted to its origin;
  - each guide's bookkeeping (`latent_shape`, `pre_filter_count`, attention `pixel_mask`) and the generated-keyframe
    record are rewritten for the tile's grid;
  - a denoise mask that is broadcast over the frame is shared by every tile.
- Refused with a plain message: downscaled guides (factor above 1), inconsistent guide bookkeeping, ControlNet.
- Still **experimental**: tested on CPU through core's own guide path and sampler with a tiny random model. Not
  benchmarked on real weights.

Evidence: 100 tests (`python -m pytest tests`).
